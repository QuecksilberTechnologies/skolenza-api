## Investigation and changes

- The unsafe hardcoding was `PolicyStatus` numeric IDs (`1,2,3,4,6,7`) in generic lifecycle and bulk import code. Those IDs are now resolved from the database using stable codes (`DRAFT`, `UNDER_REVIEW`, `APPROVED`, `PUBLISHED`, `ARCHIVED`, `REJECTED`). Missing active metadata fails clearly.
- No `Constants/JSON` catalogue or duplicate `MetaDataController` was added. Policy categories, statuses, rule types, category-rule mappings, setting definitions/options/dependencies and document types already have relational tables, seeds, foreign keys and one lookup API. JSON would create a second source of truth.
- `AttendanceLocationScope` remains enum-derived because it is a compile-time domain contract, not tenant-editable master data.
- No Angular files were changed.
