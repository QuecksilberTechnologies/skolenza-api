## Defects fixed

1. `RenameCityToLocality.sql` stopped when a legacy state had cities but no
   synchronized district. It now creates one clearly labelled holding district
   per affected state and advances the identity sequence before insertion. It
   does not guess a real geographic district.
2. `SeedTenantPolicyModules.sql` assumed `Module.PageName` existed. The standalone
   seed now adds the nullable column before upserting stable page keys.
