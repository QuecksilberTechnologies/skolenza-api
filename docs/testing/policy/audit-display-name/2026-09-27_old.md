## Investigation and changes

- Observed failure: UI attempted to match numeric `changedById` against opaque encoded string IDs
  returned by `Employee/get-all`, so the lookup could not match and showed `Employee 14`.
- Confirmed cause and evidence: the previous audit response carried only `changedById`; both grids
  called the incompatible client-side employee lookup.
- Suspected cause / remaining uncertainty: no remaining local source uncertainty. Actual target data
  and deployment require authenticated verification.
- Changed files and commit: response DTO, repository, focused backend test, endpoint/UI handoff,
  Angular audit interface, shared actor formatter, both audit grids, and focused UI tests. Commit IDs
  are recorded in Git history after commit.
- Regression scope: local tests establish the response contract, tenant filters, and UI fallback.
  They do not establish a deployed database row or live authentication/permission behavior.
