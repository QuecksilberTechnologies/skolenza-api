## Investigation and changes

The upload failure was reproduced on Draft version `4` with a valid `.pdf`.
Render application logs showed `Amazon.S3.AmazonS3Exception: The AWS Access Key
Id you provided does not exist in our records.` The request fails in object
storage before `PolicyDocument` metadata is inserted. This is a Render S3
credential/configuration issue, not a policy lifecycle or file-shape failure.

A separate live control found that cancelling a terminal bulk job returned a
successful no-op although the published endpoint contract says terminal jobs
cannot be cancelled. `BulkImportRepository` now throws `ConflictException` for
terminal cancellation, with an isolated-database regression test added. This
fix is local and requires deployment before live acceptance.
