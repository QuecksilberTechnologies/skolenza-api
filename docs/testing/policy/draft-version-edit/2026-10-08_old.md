## Investigation and changes

- Observed failure: the list showed Draft v2, but Edit displayed “Published and can no longer be edited.”
- Confirmed cause: the dialog passed only `policy.id`; its store called policy-level `getPolicy`, whose
  intended backend ordering returns the current Published version before the newer Draft.
- Change: Edit now passes `currentVersionId` and uses the existing version-specific
  `GET /api/TenantPolicy/{policyId}/versions/{versionId}` client method.
- Published immutability and backend version-selection behavior were not changed.
