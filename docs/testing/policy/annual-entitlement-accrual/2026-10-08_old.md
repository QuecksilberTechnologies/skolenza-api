# Leave annual entitlement and derived accrual amount — 2026-10-08

## Scope and expected behavior

- A Leave Accrual rule records an authoritative yearly entitlement per targeted Leave Type.
- Monthly, Quarterly and Yearly frequency automatically derives the recurring cycle amount.
- The UI does not permit a conflicting manual cycle amount.
- The API independently validates the derived amount before saving a Draft.
- A consuming leave ledger uses the remaining balance in the final cycle, preserving the exact
  annual entitlement when division requires rounding.
- Existing Published policy versions remain immutable and unchanged.

## API contract

Existing endpoints are retained; no permission or route change was introduced.

- `GET /api/TenantPolicy/lookups` supplies the new required setting metadata.
- `POST /api/TenantPolicy` and `PUT /api/TenantPolicy/{policyId}/draft` accept the calculated
  settings inside each rule's `ruleConfiguration` JSON string.
- A mismatched `amountPerCycle` produces a validation error and is not persisted.

Representative rule configuration:

```json
{
  "annualEntitlement": 20,
  "frequency": "MONTHLY",
  "amountPerCycle": 1.666667,
  "prorateNewJoiner": true
}
```
