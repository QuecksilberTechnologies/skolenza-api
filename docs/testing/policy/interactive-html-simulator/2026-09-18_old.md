# Tenant Policy interactive HTML simulator

## Environment/build

- Date: 2026-09-18
- Artifact: `docs/UIdeveloperDoc/policy-live-simulator`
- Local URL: `http://localhost:4200`
- Default API: `https://skolenza-api.onrender.com`

## Scope and scenarios

1. Render Policy Builder, All 37 APIs, Tables & lifecycle, and Local files tabs.
2. Load Travel and Leave samples; create payload contains identity, JSON rules, applicability and dynamic permission IDs.
3. Create review shows `POST /api/TenantPolicy` and `Policy`, `PolicyVersion`, `PolicyRule`, `PolicyApplicability`, `PolicyChangeAudit` before mutation.
4. Catalogue contains all 37 controller routes with method/path/permission/table impact.
5. Local save/export/import round-trips payload without bearer token or Authorization header.
6. Live connect resolves permission IDs from `/api/Navigation/my-menu`; each DDL source reports its own actual success/failure.
7. Multipart review does not fabricate or submit a file.

## Persistence and cleanup

- Only `skolenza-policy-*` localStorage keys are used.
- Clear removes only simulator keys.
- Export includes schema version, timestamp, API base and policy payload; token is excluded.
- Review actions do not mutate DB. Live writes require an explicit second confirmation.
