# Subscription billing foundation — 2026-09-24

## Scope and status

- Scope: India-first gateway-neutral billing schema, Cashfree metadata, centralized retry/grace configuration and implementation handoff.
- Status: schema and HostAdmin configuration foundation implemented. Provider/worker and sandbox acceptance are pending, so payment processing is not release-ready.

## Decisions

- Cashfree first adapter; INR and India GST launch.
- Monthly/yearly Tenant choice; immediate prorated upgrade and next-cycle downgrade.
- Host-admin partial/full refund.
- Three application retries and one-day grace, both configuration-bound.
- Webhook/reconciliation confirmation is authoritative; browser redirects cannot grant entitlement.
