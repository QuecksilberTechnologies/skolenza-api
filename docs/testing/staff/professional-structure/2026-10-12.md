### Runtime regression found and corrected

- Visual Studio exposed an API-startup failure while EF built the model:
  `A key cannot be configured on StaffJobFamilyMaster because it is a derived type`.
- Confirmed cause: the inherited `Id` key was configured separately on every TPC-derived master.
- Correction: the TPC root `InstitutionMasterEntity` now owns the key and common-property mapping;
  derived masters only select their physical table.
- A regression test now constructs the real Npgsql EF model and verifies all four physical master
  table mappings. Focused result: 4 passed, 0 failed, 0 skipped.
- The Release API was then started from the command line against local `SkolenzaDB`. It logged
  successful application startup and executed PostgreSQL commands.
- Runtime HTTP evidence: `/swagger/index.html` returned 200 (735 bytes),
  `/swagger/v1/swagger.json` returned 200 (1,595,227 bytes), and the unauthenticated
  `/api/Staff/professional-structure/positions` probe returned the expected 401.
- The temporary command-line API process was stopped cleanly after verification.

No deployed Render verification was run. No authenticated browser end-to-end StaffMember was
created in this report, so SMTP delivery and a live capability approval remain runtime checks
rather than recorded passes.

### Category, Job Family and Position cascade correction

- Browser reconciliation exposed that the Staff Category and Job Family controls could create an
  invalid independent combination, leaving Position empty.
- The existing category-filtered Position API remains authoritative. The Angular create form now
  derives available Job Families from positions returned for the selected category and enables
  Position only after a Job Family is selected.
- Browser evidence on the local authenticated UI: selecting `Teaching` exposed only `Academics`;
  selecting `Academics` then exposed `Teacher` as the configured Position.
- The persistence assignment path now rejects a position whose category differs from the saved
  StaffMember category, so a crafted request cannot bypass the UI cascade.
- Role moved beside Country, and professional-master Edit uses the existing Optimus dialog with a
  close action while Add remains in the page workspace.
- Angular development build: PASS. Focused professional-structure backend gate: 4 passed, 0 failed,
  0 skipped. Existing package/compiler warnings remain.
