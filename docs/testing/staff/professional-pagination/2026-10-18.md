## Investigation and changes

The existing category/master/Position handlers returned complete unpaged lists.
They now bind a permission-bearing paging DTO with existing central defaults,
call paged repository overloads, and return `ApiResponse.SuccessPaginated`.
Shared projections preserve the existing fields and filters. Count and page
retrieval use the already implemented `QueryPagination.ToPageAsync`; no second
paging helper or business catalogue was added. Position requirements load only
for the selected Position page, without truncating each Position's children.
Existing unpaged internal reads support Category save/profile/seed flows.

references were present in the current checkout. A normal full Debug build

duplicate replacement types or project-reference workaround was added; the
precise cause of the screenshot's previous IDE state is not established.

Production files: ProfessionalStructure DTOs, interface, repository, handlers
and controller. The existing StaffProfessionalStructure test fixture was
extended. No authentication, permission, database model, migration, Angular
