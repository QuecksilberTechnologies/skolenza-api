## Investigation and changes

- Observed failure: The public plan endpoint returned HTTP 500 only in Production mode.
- Confirmed cause and evidence: `FileStorageService` called `Amazon.RegionEndpoint.GetBySystemName` with a null `AWSUploads:Region`. Supplying `AWSUploads:Region` and `AWSUploads:BucketName` changed the same Production-mode request from HTTP 500 to HTTP 200.
- Changed files and commit: `Skolenza.api/appsettings.json`; commit pending at report creation.
- Limits of the executed verification: The deployed endpoint remains on the previous build until Render redeploys the repository commit.
