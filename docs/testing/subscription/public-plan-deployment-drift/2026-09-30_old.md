## Investigation and changes

- Observed failure: Angular called the intended GET route, but Render returned HTTP 405 even though restored plan rows exist.
- Confirmed cause and evidence: the deployed Swagger contract exposes a POST/authenticated implementation, while current source and the locally running build expose the intended anonymous GET implementation. The local GET returned plan data from the restored database.
- Configuration correction: Development uses the external Render database hostname for local Visual Studio execution. Production retains the Render-internal hostname. `FileSettings.BaseUrl` was aligned to `https://skolenza-be.onrender.com/`.
- Changed file and local commit: `skolenza.api/appsettings.Production.json`, commit `f5d1c043`.
- Deployment limitation: GitHub push could not authenticate in the non-interactive local session, so Render has not received this trigger commit.
