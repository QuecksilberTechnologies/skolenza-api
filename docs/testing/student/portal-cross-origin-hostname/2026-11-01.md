## Investigation and changes

- Confirmed cause: direct cross-origin calls reach the API with the API's Host, whereas portal handlers previously resolved tenant only from that Host; verified school origins were absent from the static CORS list.
- Controller now forwards optional `portalHostname` with backward-compatible Host fallback. Existing handlers resolve the active verified domain and retain account, password, token and tenant checks.
- The existing frontend CORS policy is extended at request time only for exact verified HTTPS school origins on portal routes. Lookup errors fail closed. No domain is marked verified by this code.
- Changed API controller/middleware/registration, central route constants, portal request DTOs and existing auth/domain test suites. No Angular changes or database migrations.
