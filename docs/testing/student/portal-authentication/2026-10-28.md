## Investigation and changes

- Observed failure: no verified live HTTP behavior is available; this is a source-phase implementation, not a runtime failure investigation.
- Confirmed cause and evidence: not applicable. Code review found an EF/SQL mismatch where EF allowed multiple or zero one-time-token targets while SQL requires exactly one. EF constraint now matches the additive SQL. Portal authorization policy also requires `TokenPurpose=Access`.
- The authenticated `/api/Student/portal-auth/me` endpoint and tenant/account-scoped persona projection are implemented. Guardian results are limited to active, date-effective `StudentGuardian` links with portal access; only minimal child identity fields are returned.
- Admission approval now queues a primary-Guardian invitation in its transaction. New Guardian accounts accept with a password; an existing same-email account must authenticate and claim the invitation. Previously inactive links for the same account are reactivated, respecting the permanent unique-link index.
- Password-reset request and completion use the same hash-only, one-time-token table. Request is generic for unknown/ineligible accounts, queues only when an active verified persona and verified domain exist, and silently suppresses email if its active template is missing. Completion updates password/security stamp, resets lockout and revokes all refresh tokens in a serializable transaction.
- Active global email templates are runtime prerequisites: `STUDENT_PORTAL_INVITATION` (`GuardianName`, `GuardianEmail`, `InvitationUrl`, `PortalDomain`, `ExpiresAtUtc`) and `STUDENT_PORTAL_PASSWORD_RESET` (`Email`, `PasswordResetUrl`, `PortalDomain`, `ExpiresAtUtc`).
- Changed files and commit: uncommitted Student portal-auth source, API policy, EF configuration, tests and docs; no commit created.
- Limits of the executed verification: source contracts only. Schema not applied; no authenticated HTTP, PostgreSQL persistence/rollback, email delivery, DNS runtime or deployment tested. No reset or invitation token/account was issued.
