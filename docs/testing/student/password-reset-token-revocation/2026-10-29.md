## Investigation and changes

Previously completion consumed only the submitted token, leaving another unexpired token for the same account usable. Completion now locks the account before locking the selected token, revalidates it, and consumes the other outstanding password-reset tokens for that institution/account within the same transaction as password change and refresh-token revocation. Invitation tokens are excluded. No schema, Angular or Render changes were made.
