## Investigation and changes

- Observed failure: Fee master APIs existed but the fee flow lacked receipt listing and admission balance reads; users could not retrieve a complete ledger summary or receipt collection through the API.
- Confirmed cause and evidence: `StudentFeeLedgerController` had no balance/receipt routes, and `IStudentFeeLedgerRepository` exposed no such queries.
- Changed files: Student fee ledger DTOs, repository interface/implementation, MediatR handlers, permission resolver, controller, fee ledger tests, UI handoff, continuation document, architecture status and testing index/report. Angular was not changed.
- Behavior: Balance is an institution-scoped read over the immutable quote and installments. It calculates the effective late fee for an overdue unpaid installment without persisting on GET; offline payment persists the late-fee amount and writes transaction+receipt in the same DB transaction. Receipt collection is paged and optionally filterable by admission/installment.
- Limits: This report covers source tests only. SQL was not applied, and endpoint execution was not verified against PostgreSQL.
