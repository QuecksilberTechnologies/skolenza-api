## Investigation and changes

Exit, Guardian-link creation and Guardian-link update use a transaction and Student row lock so the state and primary checks are performed after competing operations finish. Existing permission behavior remains unchanged. `StudentEducationIdentifier` creation, review and update now consistently store UTC values in the existing timezone-less columns without altering schema. The test creates the identifier master in a separate context: using the same context as other independent table-per-concrete-type master rows exposed an EF tracking identity collision. This was a fixture failure, not a demonstrated live endpoint failure; mixed-master tracking remains an area for separate investigation.
