## Investigation and changes

- Each arrangement owns an independent set of weekday rows; the UI previously selected the first
  active arrangement without checking its effective dates or allowing an explicit choice.
- Non-hybrid pattern forms previously offered unrelated modes. They now inherit the parent mode.
- Fixed Hybrid keeps day-level concrete modes; Flexible Hybrid is excluded from fixed patterns.
- Physical location options now require an employee assignment covering the arrangement window.
- Weekly-off rows no longer display the storage fallback mode.
