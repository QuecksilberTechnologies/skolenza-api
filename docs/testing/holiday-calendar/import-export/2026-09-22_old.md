## Investigation and changes

The existing holiday controller had CRUD only. Import and Export now use the same tenant permission behavior with their respective operation mappings. Import validates every row and active tenant location before saving, rejects duplicates within the file, skips matching active database records, and returns created/skipped counts. Export emits tenant-scoped UTF-8 CSV with the same column headers. The import is synchronous and bounded by the shared table reader (5 MB, 5,000 rows); it is not a durable BulkImportMaster job. Both production and tenant-policy seed files include Import/Export mappings. No observed functional failure remains from the focused tests. Authenticated network behavior and full-seed portability remain unverified.
