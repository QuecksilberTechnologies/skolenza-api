## Investigation and changes

- The checked-in cleanup script referenced retired insurance/leave tables and did not include newer policy-engine tables. Each failed attempt rolled back in its transaction.
- The successful execution copy used live FK metadata to delete current restrictive policy tables before Employee/Tenant rows and omitted the script's unrelated location-upsert section, honoring the tenant-only scope.
- The original ISO script is insert-only and failed against the existing 249-row catalogue. The existing ID-preserving variant was used so foreign-key IDs remained stable.
- No application source or checked-in seed SQL was changed by this operation.
