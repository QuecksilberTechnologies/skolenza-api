## Investigation and changes

- Observed failure: the registration screen displayed only `An error occurred while creating tenant. Please try again later.`
- Confirmed cause and evidence: tenant cleanup had left four orphan rows in `TenantEncryptionKeys`. With no tenants remaining, the next tenant identity reused a low value and violated `UQ_TenantKey_TenantId` while creating tenant security data.
- Suspected cause / remaining uncertainty: the table currently permits an encryption-key row to remain after its tenant is removed. A schema or cascade change was outside this request and was not introduced.
- Changed files and commit: backend handler, shared error constants, endpoint documentation and the existing Host API regression test were updated in the uncommitted backend working tree. Angular registration response typing, component message handling and the existing component specification were updated in the uncommitted Angular working tree.
- What the executed regression tests establish and do not establish: the tests establish transaction outcomes, safe stage-specific failures, known database conflict mapping, email-after-commit behavior, Angular message selection, production compilation and the complete local database creation path with rollback. They do not establish deployed API behavior or a production database migration.
