- Confirmed cause and evidence: creation was guarded by `onboardingRequest != null`, and the narrow update only staged the Tenant entity.
- Suspected cause / remaining uncertainty: deployed API/Render state has not been inspected after deployment.
- Changed files and commit: Tenant registration/update handlers, Tenant configuration repository/interface, constants, controller documentation, automated tests and documentation in the current uncommitted working tree.
- What the executed regression tests establish and do not establish: they establish local handler behavior, transaction rollback and protected Role mapping. They do not establish deployed HTTP behavior or Render persistence.
