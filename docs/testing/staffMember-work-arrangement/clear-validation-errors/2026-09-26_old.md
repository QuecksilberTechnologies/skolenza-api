## Expected and implemented behavior

The validator distinguishes these conditions in order: employee missing/deleted, employee inactive,
location missing/deleted, location inactive, incompatible location type, assignment missing, assignment
inactive, assignment not primary, attendance disabled, late start, early end, and an open-ended arrangement
covered only by a finite assignment.

Repository diagnostic queries include `!x.IsSoftDeleted`. Therefore a soft-deleted employee, location,
or assignment is ignored even if `IsActive = true`; it cannot cover an arrangement.
