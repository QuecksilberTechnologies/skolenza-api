- Observed failure: Location and arrangement records were validated independently; active checks ignored effective-window overlap.

- Resolved design gap: Generic PolicyVersion now owns a typed one-to-one `AttendancePolicyVersionConfiguration`; no rule-JSON parsing or legacy AttendancePolicy dependency is used.
