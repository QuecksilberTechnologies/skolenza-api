## Investigation and changes

- Observed failure: the overlap rule existed, but create, update and activation repeated a boolean repository call and returned only a generic conflict message.
- Confirmed cause and evidence: three handler paths independently called `CurrentArrangementExistsAsync`; the repository discarded the conflicting date range.
- Suspected cause / remaining uncertainty: none for the code path; authenticated concurrent-write behavior is not exercised locally.
- Changed files and commit: application validator, repository contract/implementation, constants, automated tests, UI handoff and this report; commit pending.
- What the executed regression tests establish and do not establish: overlap boundaries, shared handler wiring, repository filtering, build compatibility and local API availability pass. They do not establish authenticated tenant mutation or deployment.
