## Investigation and changes

- Observed failure: Render stopped at `dotnet restore skolenza.api/skolenza.api.csproj` because Linux paths are case-sensitive.
- Confirmed cause and evidence: the repository stores project folders, project files and output assembly with the `Skolenza.*` casing. The Dockerfile and inter-project references used lowercase paths, which Windows tolerated but the Render Linux build did not.
- Changed files and commit: `Dockerfile`, all dependent project-reference files and `Skolenza.sln`; commits recorded in Git history.
- Limits of the executed verification: Docker image creation was blocked locally because Docker Desktop was not running. Successful Render deployment remains separate acceptance evidence.
