# Dashboard staff date widget query translation — 2026-10-13

## Scope

The institution dashboard failed while loading upcoming birthdays because EF Core attempted to apply `DateOfBirth` filtering after projecting a staff entity through `StaffMemberDashboardRow`. Recent-onboarding queries used the same composition pattern.

## Change

- Active institution staff filtering is centralized in `ActiveStaffMembers`.
- Birthday and onboarding date filters, ordering and limits are applied to the entity query before department, designation and role projection.
- The dashboard response contract and permission pipeline are unchanged.
