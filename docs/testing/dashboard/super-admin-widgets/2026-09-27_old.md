## Investigation and changes

The legacy `StatDataController` contains static dashboard actions and was left unchanged. The new
controller delegates through MediatR. Repository queries filter tenant ownership and soft deletion;
employee list IDs are encoded. Storage, hiring, open-position, and pending-approval values are
explicitly temporary because their authoritative modules are not available in this scope.
