## Investigation and changes

- Observed failure: the browser received the safe generic `INTERNAL_SERVER_ERROR` envelope from Education create.
- Confirmed cause: `CreateEducationRequestDTO.StartDate/EndDate` are nullable `DateTime`, while `EmployeeEducation.StartDate/EndDate` are nullable `DateOnly`; the create AutoMapper map had no conversion.
- Changed files: create mapping, create-handler score-type validation, focused regression test, UI handoff and this report.
- The fix preserves the existing encoded EmployeeId, permission, transaction, file-upload and repository flows.
- Automated mapping tests establish the previously failing boundary. They do not establish authentication, database insert, object storage or deployed behavior.
